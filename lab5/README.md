Название проекта: «Умный дом». В проекте три небольших модуля, каждый показывает один паттерн проектирования:

* `proxy.py` - Proxy: прокси для умной лампы (ленивое подключение, кеш статуса).
* `adapter.py` - Adapter: старый пульт от телевизора управляет новой умной колонкой.
* `bridge.py` - Bridge: датчики (температура, влажность) и способы оповещения (телефон, колонка).
